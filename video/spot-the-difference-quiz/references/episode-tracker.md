# Episode tracker

> Updated 2026-11-01 (v1.0.0): YouTube standard. The answer is revealed
> inside the video, so there is no separate answer-post time to record.

Copy this table into the series folder and update it on every post. It is
what enforces the no-repeat-topic rule. Difficulty is Medium or above only
(no Easy, no rotation); Medium = 3 differences, Hard = 5 differences.
One row per episode.

| # | Topic | Difficulty | Differences (color / missing / count) | Posted | Video ID / URL | QA result | Hold start (if any) | Found-it comments | Notes |
|---|-------|------------|----------------------------------------|--------|----------------|-----------|---------------------|-------------------|-------|
| 01 | kitchen | Medium | curtains yellow→green / red kettle gone / oranges 4→3 | | | | | | |
| 02 | | | | | | | | | |

Rules:
- Never repeat a topic already in this table.
- Difficulty is Medium or above only; record the count (3 or 5).
- Record the QA result per episode: passed, or eye-pass / pixel-map-fail
  with a 1-hour user-review hold start date. A hold video auto-publishes on
  day 3 if the user does not veto; an eye-check failure is never
  auto-published.
- When testing a new hashtag set, note it in Notes and compare episodes at
  the same age — change only one variable at a time.
