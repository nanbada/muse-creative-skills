# Captions, footers, and comments

> Updated 2026-11-01 (v1.0.0): YouTube Shorts standard. Footer lines are
> unchanged from v1.5; the caption hook no longer claims "in 10 seconds"
> because the find window is 15 seconds (5 seconds still + 10-second
> countdown) and the target real search time is 30 seconds or more.

## Problem-card footer lines (updated 2026-11-01, v1.5)

- Medium: `★★☆ MEDIUM · Can you find all 3?` (number matches the count)
- Hard: `★★★ HARD · Can you find all 5?`
- Easy is excluded from this series.

## Answer-card footer lines (updated 2026-11-01, v1.5)

The problem is already over, so never reuse the problem footer here.

- Medium: `★★☆ MEDIUM · How many did you spot?`
- Hard: `★★★ HARD · How many did you spot?`

Superseded v0.2.0 lines (do not use): `Only 1 in 10 finds all 3!`,
`Only geniuses find all 3!`, and any Easy line.

## Shorts caption structure

Line 1 is the hook. Line 2 is difficulty plus provocation. Line 3 asks for a
like and a Found it comment. Line 4 asks for a Hint comment.

```
Can You Spot All 3 Differences? 🤔
Level ★★☆ Medium — Can you find all 3 before the timer runs out? 😱
Double-tap ❤️ if you found them! Comment "Found it!" 👇
Stuck? Comment "Hint" 💡 and I'll drop one!
#FindTheDifference #SpotTheDifference #PuzzleChallenge #BrainTeaser #VisualPuzzles
```

Change only the level line for other tiers.

- Hard line 2: `Level ★★★ Hard — Can you find all 5 before the timer runs out? 🧠`
- Easy is excluded, so there is no Easy caption line.
- Superseded hook (do not use): "in 10 Seconds" — the find window is
  15 seconds and the target real search time is 30 seconds or more.

## Long-form caption structure

Main title in English, description and tags multilingual (English +
Japanese + Chinese, plus the landmark's country language where applicable).
AI disclosure ON, not made for kids.

```
Can You Spot All the Differences? | <Landmark / Scene> — <Medium/Hard>
<One line on the scene, no spoilers.>
How many did you find? Comment your count! 👇
#FindTheDifference #SpotTheDifference #BrainTeaser #VisualPuzzles
```

## Answer carousel caption (superseded — do not use)

The answer is revealed inside the video, so there is no answer carousel.
Kept here only as history:

```
Can You Spot All 3 Differences? 🤔
Swipe to check the answers! 👉
Comment how many you found! 👇
#FindTheDifference #SpotTheDifference #PuzzleChallenge #BrainTeaser #VisualPuzzles
```

## Guide comment (post right after the reel goes live)

```
Did you find all 3? 👀 Double-tap ❤️ if you did! Stuck? Comment 'Hint' 💡 and I'll drop one! 👇
```

## Hashtag discipline

Keep one core set across the series so you can compare episodes fairly. If you
test a new set, change only the hashtags and keep the caption lines identical,
then compare episodes at the same age after posting. A new tag set that fails
to beat the old one is information, not failure.
