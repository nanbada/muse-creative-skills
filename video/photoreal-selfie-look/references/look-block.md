# Photoreal Selfie Look — English blocks

Paste the Look block verbatim at the end of the video prompt, then the Ban block.
Keep both in English inside the prompt; user-facing notes stay in Korean.

## Look block

```
Smartphone front-camera aesthetic, like a TikTok influencer filming herself with a beauty filter on.
Not clean high-definition footage. Skin softened and slightly brightened by the beauty filter,
texture lightly evened out, but never fully smooth plastic skin.
Fine random grain and slight color noise remain in midtones and shadows.
During fast motions (picking up the phone, putting it down, sudden approach toward the face,
sweeping hair up), always add clear motion blur and momentary loss of focus.
Maintain focus breathing, rolling-shutter distortion, subtle exposure drift,
subtle white-balance drift, light smearing from noise reduction,
block noise from SNS platform compression, and the imperfect detail
typical of a smartphone front camera.
Facial features always recognizable, but never keep the entire frame sharp at all times.
Handheld smartphone micro-shake throughout — irregular, small, never steadicam-smooth.
```

## Ban block

```
No text, no subtitles, no logos, no watermarks.
No zero-noise footage, no fully sharp frames from start to finish,
no excessive HDR, no studio-grade post-processing, no cinematic clean look,
no steadicam-like smooth movement, no excessive handshake.
```

## Framing cue (vertical)

```
Vertical 9:16 portrait framing, subject centered.
```
