# 종 카드 — 종별 단계 구성·개수 회계·키워드·상품 매핑

시리즈를 시작할 때 종 카드 1장을 확정한다. 환경 락(화분·배경·빛·카메라)은 카드에 한 번 적고 전 프레임 verbatim으로 쓴다.
퀵 10초형의 완성 프롬프트 팩(오이·토마토·해바라기·망고·바질)은 `species-packs.md`와 `quickstart-prompts.md`에 있다.

## 딸기 (완성 카드 — 샘플 역설계)

- **환경 락**: 테라코타 화분 + 검은 흙 + 나무 테이블 + 녹색 정원 보케 + 좌상단 아침 햇살 (전문: `stage-prompt-system.md`)
- **단계 (7)**: F1 파종 → F2 발아 → F3 잎 성장 → F4 개화 → F5 어린 열매 → F6 착색 → F7 완숙
- **개수 회계**: 꽃+봉오리 6개 (F4) = 초록 열매 6개 (F5) = 완숙 6개 (F7). 큰 것 4 + 작은 것 2, 위치 고정. 잎은 F7 기준 11장
- **손글씨 키워드**: 파종 "씨앗 심는 날" / 발아 "싹이 났어요" / 잎 성장 "쑥쑥 자라요" / 개화 "꽃이 피었어요" / 결실 "열매가 열렸어요" / 착색 "빨갛게 익는 중" / 완숙 "수확의 기쁨"
- **핵심 키워드 (검증 사실)**: 장미과예요 / 씨는 겉에 약 200개 / 먹는 부분은 꽃턱 / 봄의 첫 열매 / 런너로 번식
- **재미 문구**: "사실은 장미 친척!" / "씨는 겉에 달렸어요" / "작은 점이 진짜 열매"
- **상품 매핑**: 딸기 모종·씨앗, 딸기 전용 비료, 화분+흙 세트

## 오이 (퀵형 대표 카드 — 환경 변형 B)

- **환경**: 투명 유리화분 + 검은 배경 + 스튜디오 조명. **뿌리가 유리 너머로 보이는 것**이 볼거리. 완성 프롬프트: `quickstart-prompts.md` (worked example)
- **단계 (5)**: 씨앗 → 발아 (뿌리 하강 + 싹) → 잎 성장 (뿌리망 확장) → 잎 무성 → 작은 오이 형성
- **개수 회계**: 퀵형 원문은 개수를 못 박지 않는다. 정밀형으로 만들 때는 마지막 프레임 오이 개수를 명시한다 (예: 3개)
- **손글씨 키워드**: "씨앗 심는 날" / "뿌리가 자라요" / "싹이 났어요" / "잎이 쑥쑥" / "오이가 열렸어요"
- **핵심 키워드 (검증 사실)**: 박과예요 / 수분 약 95% / 발아 3~10일 / 파종부터 수확 50~70일
- **재미 문구**: "거의 물이에요, 물!" / "뿌리부터 쭉쭉 마셔요" / "여름엔 하루가 달라요"
- **상품 매핑**: 오이 씨앗, 채소 범용 비료, 투명 화분 세트

## 방울토마토 🛠

- **환경 락**: 딸기와 동일 문형, 화분은 한 단계 큰 테라코타 (지지대 1개는 F3부터 환경 락에 포함해 고정)
- **단계 (7)**: F1 파종 → F2 발아 → F3 잎·줄기 성장 (지지대에 닿음) → F4 개화 (노란 꽃송이) → F5 초록 열매 → F6 착색 (주황) → F7 완숙 (빨간 방울이 송이로)
- **개수 회계**: 꽃송이 1개 = 열매 송이 1개. 송이당 열매 8~10개로 못 박고 전 단계 유지
- **키워드**: "씨앗 심는 날" / "싹이 났어요" / "줄기가 쑥쑥" / "노란 꽃이 피었어요" / "열매가 열렸어요" / "주황빛으로 익는 중" / "수확의 기쁨"
- **핵심 키워드 (검증 사실)**: 가지과예요 / 고향은 남아메리카 / 빨간 색은 라이코펜 / 알고 보면 과일 (식물학상 베리)
- **재미 문구**: "옛날엔 구경만 했대요" (유럽에선 관상용이었던 역사) / "채소인 척하는 과일" / "빨개질수록 달콤해요"
- **상품 매핑**: 방울토마토 씨앗, 토마토 전용 비료, 지지대·화분 세트

## 고추 🛠

- **단계 (7)**: F1 파종 → F2 발아 → F3 잎 성장 → F4 개화 (흰 작은 꽃) → F5 어린 열매 (위로 솟는 초록 고추) → F6 비대 (짙은 녹색, 광택) → F7 완숙 (빨간 고추)
- **개수 회계**: 대표 열매 5개 위치 고정 (꽃 5개에서 추적)
- **키워드**: "씨앗 심는 날" / "싹이 났어요" / "쑥쑥 자라요" / "하얀 꽃이 피었어요" / "고추가 열렸어요" / "통통해지는 중" / "빨갛게 익었어요"
- **핵심 키워드 (검증 사실)**: 가지과예요 / 매운맛은 캡사이신 / 빨간 색은 캡산틴
- **재미 문구**: "익으면 단맛도 올라요" / "햇빛 먹고 매콤하게"
- **상품 매핑**: 고추 모종·씨앗, 고추 전용 비료

## 바질 (잎채소형 — 열매 없음) 🛠

- **단계 (5)**: F1 파종 → F2 발아 → F3 잎 성장 (잎 6~8장) → F4 무성 (잎 15장+, 풍성) → F5 수확 직전 (최대 풍성, 윤기)
- **개수 회계**: 열매 대신 잎 수 증가만 추적. 꽃이 피면 실패 (잎채소는 개화 = 말기) — 제외 블록에 개화 금지 명시
- **키워드**: "씨앗 심는 날" / "싹이 났어요" / "잎이 쑥쑥" / "싱싱하게 무성" / "수확의 기쁨"
- **핵심 키워드 (검증 사실)**: 꿀풀과예요 / 이름의 뜻은 '왕' / 발아 7~10일 / 꽃을 따줘야 잎이 무성
- **재미 문구**: "허브의 왕이래요" / "꽃 따면 잎이 쑥쑥" / "이름값 하는 향기"
- **상품 매핑**: 허브 씨앗 세트, 실내 화분, 유기질 비료

## 해바라기 (키 성장형) 🛠

- **환경 락 변형**: 화분 → 정원 흙 (큰 화분 또는 노지). 카메라는 단계마다 같은 구도를 유지하되 최종 높이에 맞춰 F1부터 넓게 잡는다 (성장해서 프레임 밖으로 나가면 실패)
- **단계 (6)**: F1 파종 → F2 발아 → F3 줄기 성장 → F4 봉오리 → F5 개화 (꽃이 고개를 듦) → F6 만개 (씨방 형성)
- **키워드**: "씨앗 심는 날" / "싹이 났어요" / "하늘 향해 쑥쑥" / "봉오리가 맺혔어요" / "꽃이 피었어요" / "활짝 웃는 해바라기"
- **핵심 키워드 (검증 사실)**: 국화과예요 / 어린 꽃만 해를 따라 돌아요 / 씨 무늬는 피보나치 나선 / 씨가 1,000~2,000개 / 꽃 한 송이 = 작은 꽃 수천 개
- **재미 문구**: "해를 따라 고개가 슝" / "씨앗 무늬에 수학이!" / "다 크면 동쪽만 봐요"
- **상품 매핑**: 해바라기 씨앗, 원예용 흙·비료

## 망고 (퀵형 카드 — 열매 없는 나무형) 🛠

- **환경**: 투명 유리화분 (변형 B) 기본. 완성 프롬프트: `species-packs.md`
- **단계 (5)**: 큰 씨앗 → 발근 (굵은 직근 하강) → 발아 → 새잎 전개 (적동색→녹색) → 튼튼한 묘목. **열매 단계 없음** — 최종 볼거리는 광택 나는 잎과 뿌리망
- **개수 회계**: 열매 대신 잎 뭉치(플러시) 횟수로 추적
- **손글씨 키워드**: "씨앗 심는 날" / "뿌리가 내려요" / "싹이 났어요" / "새잎이 반짝" / "튼튼한 묘목"
- **핵심 키워드 (검증 사실)**: 옻나무과예요 / 과일의 왕 / 고향은 남아시아 / 4,000년 넘게 키운 과일 / 새잎은 붉게 나와요
- **재미 문구**: "과일의 왕, 납시오!" / "새잎은 구릿빛으로" / "느긋하게 크는 중"
- **상품 매핑**: 망고 묘목, 과수용 비료, 큰 화분 (씨앗은 과일 채취가 일반적이라 묘목·화분 위주)

## 새 종 카드 작성 규칙

1. 단계는 5~7개. 반드시 파종(F1)과 최종(수확/만개) 단계를 포함한다
2. 개수 회계의 단위를 정한다 (열매 수 / 송이 수 / 잎 수) — 추적 불가능한 종은 대표 개체 수를 줄여 고정한다
3. 환경 락은 딸기 문형을 뼈대로, 화분·표면·배경만 종에 맞게 교체한다
4. 키워드는 단계당 1개, 7자 내외, 중년·노년이 한눈에 읽는 말투로
5. 상품 매핑은 그 종을 실제로 키울 때 사는 것 (씨앗/모종 + 전용 비료 + 화분 세트)만
6. 핵심 키워드는 **식물 이름으로 사실을 확인한 것만** 쓴다 (과·원산·특성·재배 수치). 확인이 안 되면 넣지 않는다 — 새 종은 검증 후 핵심 키워드·재미 문구를 채운다

## 핵심 키워드 검증 출처 (2026-10-21 웹 확인)

- 딸기: 장미과, 빨간 부분은 꽃턱이고 진짜 열매는 표면의 수과, 평균 약 200개, 씨를 겉에 다는 유일한 과일, 봄의 첫 열매 (The Spruce, 농업교육 자료 등)
- 오이: 박과, 수분 약 95%, 발아 3~10일, 수확 50~70일 (원예 가이드 복수)
- 토마토: 가지과, 남아메리카(안데스) 원산, 유럽 초기 관상용·독성 의심, 빨간색은 라이코펜, 식물학상 베리 (Britannica 등)
- 고추: 가지과, 매운맛은 캡사이신, 빨간색은 캡산틴, 익으면 당도 상승 (ScienceDirect 개요 등)
- 바질: 꿀풀과, 이름은 그리스어 basileus(왕)에서, "허브의 왕", 발아 7~10일, 꽃을 따주면 잎 생산 유지 (UGA, 어원 자료 등)
- 해바라기: 국화과, 어린 개체만 해를 따라 회전하고 성숙하면 동향 고정, 씨앗 배열은 피보나치 나선, 씨 1,000~2,000개, 두상화는 작은 꽃 수백~수천 개 (Macquarie Univ 등)
- 망고: 옻나무과, "과일의 왕", 남아시아 원산, 4,000년 이상 재배, 어린 잎은 붉은빛에서 녹색으로 (원예·식물학 자료 복수)
