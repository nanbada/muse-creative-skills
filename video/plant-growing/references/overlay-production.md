# 오버레이·조립·스틸컷 — 손글씨 키워드 + 롤링 텍스트 + 상품 동선

원칙: **텍스트는 전부 후반 코드 오버레이** (코드 렌더 원칙). 생성 모델에 글자를 맡기지 않는다.

## 1. 손글씨 키워드 (주요 장면)

- **타이밍**: 각 단계가 시작되는 순간 등장 → 2.5초 이상 유지 → 페이드아웃. 단계당 1개
- **문구**: 종 카드의 키워드 세트 사용 (단계당 1개, 7자 내외)

**문구 3종 체계** (종 카드에 종별로 준비되어 있다)
| 종류 | 역할 | 배치 |
|---|---|---|
| 단계 키워드 | 지금 무슨 단계인지 ("꽃이 피었어요") | 단계 전환 시점, 단계당 1개 |
| 핵심 키워드 | 식물 이름으로 확인한 사실 ("씨는 겉에 약 200개") | 주요 장면·스틸컷. 회차당 2~3개 |
| 재미 문구 | 후크와 여운 ("사실은 장미 친척!") | 오프닝 3초 또는 엔딩 직전 1개 |

- 핵심 키워드는 **검증된 사실만** 쓴다. 출처 없이 지어낸 수치·효능은 금지 (종 카드의 검증 출처 참조)
- 재미 문구도 사실에 기대어 만든다 — 사실과 어긋나는 과장은 문구가 아니라 오류다
- **스타일**: 예쁜 손글씨체 (한글 손글씨 폰트 — 예: 나눔손글씨 펜/붓 계열. 사용 전 상업 이용 라이선스 확인)
  - 크기: 1080폭 기준 **96px 이상** (중년·노년 가독성 하한)
  - 색: 흰색 + 부드러운 그림자, 또는 연노랑/연분홍 — 배경과 명도 대비 확보
  - 위치: 화면 상단 1/3의 여백. **식물 중심부를 절대 가리지 않는다**
- **스틸컷용 변형**: 스틸에는 사진 위 얇은 흰색 아웃라인 + 손글씨 메모 + 점선 화살표를 얹는 손그림 주석 방식을 프롬프트로 적용할 수 있다. 단, 영상 키워드는 코드 오버레이가 기본 (글자 정확도)

## 2. 롤링 텍스트 (생활 꿀팁·양생)

- **위치**: 화면 하단 띠 (하단 12~18% 구간). 반투명 어두운 띠를 깔아 가독성 확보
- **글꼴**: 손글씨가 아닌 **굵은 고딕 64px 이상** — 흘러가는 텍스트는 가독성이 우선
- **속도**: 느리게. 문장 1개가 화면을 지나는 데 12~18초 🛠 (노년층 낭독 속도 기준)
- **내용**: `tips-bank.md`에서 회차마다 3~5문장 순환. 종과 연결되는 원예 팁 1개 이상 포함
- **금지**: 효능 단정 (치료·예방·개선 보장), 특정 약품·건강식품 권유, 공포 조장 문구

## 3. 조립 (ffmpeg)

```
구간 클립 (I2V) → concat → 키워드 오버레이 → 롤링 텍스트 → BGM → 엔드카드
```

- 구간 클립은 동일 코덱·해상도·fps로 통일해 concat (재인코딩 1회로 묶어 오버레이와 함께 처리)
- BGM: 잔잔한 어쿠스틱/피아노, 저작권 프리 음원만. 네이티브 오디오(환경음)는 살리거나 BGM 아래로 낮춘다
- **엔드카드 3초**: 완숙 프레임 정지 + "씨앗·비료는 고정 댓글에 있어요" 손글씨 + 아래로 화살표 (상품 링크 동선)
- 최종 검증: 최종 렌더 파일에서 단계 경계마다 프레임 추출해 키워드 위치·개수 회계·텍스트 깨짐 확인 (프리뷰가 아닌 최종본 검증)

## 4. 스틸컷 3~6장

단계 프레임이 곧 스틸 원본이다. 아래에서 3~6장을 고른다:

| 용도 | 추천 프레임 |
|---|---|
| 썸네일/커버 | F7 완숙 (가장 화려한 장면) + 손글씨 키워드 합성 |
| 캐러셀·커뮤니티 | F1 파종 → F4 개화 → F7 완숙 (전후 대비 3장) 기본 세트 |
| 상품 카드 | F7 완숙 + 종 카드의 상품명 손글씨 메모 |
| 풀세트 (6장) | F1·F2·F3·F4·F6·F7 |

- 수출: 원본 해상도 JPG (영상과 동일 9:16) + 손글씨 합성본 2종
- 스틸에도 AI 생성 표시를 유지한다

## 5. 공개·수익화 동선

- **링크 배치**: 고정 댓글 1순위 (씨앗/모종 + 비료), 설명란 2순위, 엔드카드는 고정 댓글로 유도
- **상품 매칭**: 종 카드의 상품 매핑만 링크한다 (영상에 나온 종과 무관한 상품 금지)
- **표시 의무**: 제휴 링크 문구 ("이 링크로 구매하시면 일정 수수료를 받아요" 등 경제적 이해관계 표시) + AI 생성 표시 — 플랫폼·국가 규정 확인 후 발행
- **발행 게이트**: 영상·스틸·링크 모두 게시 전에 사람이 확인한다
