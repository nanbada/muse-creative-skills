# Post text template (fashion-motion-video)

## 2026-10-31 revision — minimal post (supersedes the full-spec template below)

Interested viewers go to the detail page for details, so the post
does NOT carry colour, fabric, sizes, lengths, or a review dump.
Keep it to 1–2 lines only:

```
{{추천 분위기/상황 1–2줄}} — {{제품명}}, {{소재}}, {{색상}}
{{상세페이지 링크}}
```

Rules:

- The 1–2 lines answer "where / when I would wear this" — a vibe
  or situation, not a spec list.
- Product name, fabric, and colour appear briefly, once.
- Always include the detail-page link.
- Never invent a product name, price, or feature. Note the
  detail-page fetch date in the job notes, and re-check the price
  before posting.

## Old full-spec template (superseded 2026-10-31, kept for reference only)

Do not use this layout for new jobs unless the user explicitly
asks for a full-spec post:

```
{{제품명}}, {{가격}}
색상: {{색상}}
소재: {{소재}}
사이즈: {{사이즈}}
총기장: {{총기장}}
특징: {{특징}}
상세페이지: {{상세페이지 링크}}

인기 리뷰 요약:
- {{리뷰 요약 1}}
- {{리뷰 요약 2}}
```

- Keep the review summary to 1–5 short lines, only from reviews
  actually shown on the detail page. If there are no usable
  reviews, delete the whole review section.
- Never invent a review, a rating, or a reviewer name.
