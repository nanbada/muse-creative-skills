# YouTube Shorts Growth — topic consistency + frame control

Source: user-supplied Korean community lecture (Chapter 3, 2026-10-03, user
pasted it as the reference strategy). This is a mentor's heuristic framework,
not verified universal fact. Treat its claims as strategy hypotheses; always
validate against real channel data before investing.

## When to use

- Choosing a Shorts channel topic / narrowing the topic frame.
- Picking one of the three growth strategies for a beginner–intermediate channel.
- Title + thumbnail pattern design for Shorts (2026 feed).
- Benchmarking competitor channels or diagnosing slow growth.

## Core principle

The algorithm optimizes for one question: **"Will the person who watched the
last video also watch the next one?"** Exposure widens from broad category
(e.g., animals) then narrows by observed response (e.g., dog lovers). Topic
drifts slow growth because the next-video probability drops.

- **Topic frame** (프레임): a hierarchy from broad to narrow, e.g.
  animal → cute animal clips → cats → ragdolls. Narrower frame = higher
  next-video probability = faster growth.
- **Trade-off**: a frame that is too narrow exhausts material quickly
  (only lions → limited usable clips); a frame that is too broad dilutes the
  audience (mixed topics → inconsistent views). Balance is the game.
- **Consistency defends the floor**: consistent topic raises the view floor
  (e.g., stable 200k × 6 = 1.2M beats spiky 10k~2M if the floor holds),
  but raising the ceiling from a stable floor demands high craft.

## Three strategies (choose one first)

| Situation | Strategy | Why |
|---|---|---|
| Want to get established fast, have decent material | **5-3: big topic + very narrow frame (recommended)** | Best growth/stability balance |
| Already started narrow, want to expand | **5-1: gradually widen the frame** | Keep existing viewers, grow the pie |
| Have the craft and want to chase big hits | **5-2: mixed topics from the start** | Max traffic, high difficulty |

### 5-3 — Narrow frame inside a mass topic (recommended)

1. Pick a big-pie mass topic: "고양이", "리트리버", "전투기", "라면 레시피".
   Too narrow (a single ragdoll cat) → material dries up. Validate via YouTube
   search autocomplete + top channels before committing.
2. Lock positioning: channel name, profile, banner, description make the topic
   obvious within 3 seconds (like "냥냥펀치" = cats only).
3. Upload rules (minimum 30 videos): every video inside the frame; topic
   visible in title, thumbnail, first 3 seconds; ≥1 upload/day for Shorts.
4. Expand timing (after ~10–30k subs): only within the same parent topic
   (고양이 → 고양이 정보 → later 강아지).
5. Benchmark: copy title patterns, thumbnail colors, TTS voice, letterbox
   style, BGM from top channels. No topic drift for the first 30.

### 5-1 — Gradually widen the frame

1. Start ultra-narrow ("테슬라 사고/리뷰" only; "선수 A" only).
2. Fix identity with 30–50 videos; don't drift until the view floor stabilizes.
3. Expand in stages: variation of the original (테슬라 → Tesla game
   simulations) → adjacent same-parent material (자동차 전반) → memes/games
   the audience naturally accepts.
4. Checklist per expansion: would existing viewers say "this is our channel's
   video"? Keep the original keyword in titles.

### 5-2 — Mixed topics from the start (advanced)

1. Daily material routine: harvest viral clips from the last 1–2 weeks on
   TikTok/Shorts/Reels; filter out overused material (skip anything seen 3+
   times in Korean Shorts).
2. Quality bar: 15–45s, clean source footage, hand-polished script (no AI voice
   telling).
3. Upload 20–30 high-quality videos across topics; tilt toward whichever topic
   pattern shows traction.
4. Warning: requires material sense + editing skill; expect spiky views.

## Title + thumbnail patterns (2026 Shorts)

Shorts autoplay in-feed, so titles/thumbnails mostly drive CTR on search,
channel pages, and recommendations. Rule: **topic consistency + curiosity gap**.
Title and thumbnail must complement each other, never repeat the same line.

### Title rules (all strategies)

- ≤40 chars recommended (mobile cutoff), max 60.
- Core keyword first (search + algorithmic classification).
- Structure: [topic/keyword] + [curiosity/twist/outcome] + [specific detail].
- Banned: exaggerated clickbait, title/content mismatch (raises churn → penalty).

Examples (narrow-frame animal):
- "고양이 꾹꾹이 하다가…"
- "렉돌이 사냥 실패하는 순간"
- "이 고양이는 진짜로 다이어트 중?"

### Thumbnail rules (Shorts-specific)

- 1080×1920 or 2160×3840 (9:16).
- One focus only: expressive face, strong visual, or the twist moment.
- Text ≤1–3 words, bold 고딕, high contrast (white+black outline or
  yellow+black background). Fix one brand color per channel.
- Test: understandable within 3 seconds on a small phone screen.

### Pre-upload checklist

- [ ] Topic keyword inside the first 15 chars of the title?
- [ ] Thumbnail alone screams "this channel"?
- [ ] Title and thumbnail don't say the same thing?
- [ ] Text readable on a small mobile screen?
- [ ] Would a viewer of the previous video naturally watch this one?

## Operating rules

- **Manual first, automate later**: hand-write scripts and edit until the
  pattern is mastered; only then discuss automation. (Aligns with standing
  user rule: drafts/validation before any automation of published content.)
- Benchmark 3–5 winning channels: record font, size, color, letterbox, BGM,
  TTS (the source recommends 타입캐스트 클래식), script tone, conjunctions.
- **30-video rule**: keep any strategy consistent for at least 30 uploads
  before judging.
- No fabricated facts in scripts; AI-narrated feel ("AI 티") is an edit fail.
- Distrust fixed formulas ("5 min a day = monthly fortune"); YouTube resists
  schematization — analyze, don't shortcut.
