# Fallback rules — when material is thin

Priority order: **ask > safely generalize > omit**. Fabrication is not an option.

| Tier | Examples | When unverifiable |
|---|---|---|
| **Tier 1 — identity** | Exterior, signage, signature space | Do not emit block A. Emit block B only and request photos / URL. |
| **Tier 2 — supporting detail** | Interior structure, window views, facilities | Ask the user to confirm. If unobtainable, generalize to the category level — but only if the scene still passes the swap test; otherwise delete the scene. |
| **Tier 3 — atmosphere** | Crowd density, weather, time of day | Mark as "연출 선택" (director's choice) and decide freely. |

## Standing rules

- Time-sensitive facts (hours, prices, awards, founding year, visitor counts,
  events): no V tag → don't write them. Even with V, leave them out by default.
- Generalizing means moving up to the category level, never importing another
  place's features.
- In non-interactive runs (no way to ask): attach a "needs confirmation" list
  to the prompter; if Tier 1 fails, emit block B only.
- **No first-person fabrication** (standing user rule): no reviews, interviews,
  "I visited" narration, ratings, or quotes. On-screen people are anonymous
  visitors performing verified activities — staging, not testimony.
