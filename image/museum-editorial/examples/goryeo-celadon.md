# 예시: 청자 상감운학문 매병 (한국어)

스킬 워크플로 그대로 실행한 테스트 결과물이다.

## 사실 검증

- V: 국보 제68호 (1962년 12월 20일 지정) — 국가유산포털/위키피디아
- V: 고려 12세기 후반 제작 — 위키피디아
- V: 높이 42.1cm, 입지름 6.2cm — 위키피디아
- V: 흑백 상감 운학문 (원 안의 학은 위로, 원 밖의 학은 아래로) — 위키피디아
- V: 간송미술관 소장 — 위키피디아
- 제외: 없음 (미확인 항목 없음)

## 붙여넣기용 프롬프트

주제: 청자 상감운학문 매병 (靑磁 象嵌雲鶴文 梅甁, Celadon Prunus Vase with Inlaid Cloud and Crane Design)

검증된 사실 (포스터 텍스트에 이 범위 안에서만 사용):
국보 제68호 (1962년 12월 20일 지정) / 고려 12세기 후반 / 높이 42.1cm /
흑백 상감 운학문 — 원 안의 학은 하늘을 향해 오르고 원 밖의 학은 땅을 향해 내림 /
간송미술관 소장

주제를 중심으로 동양 박물관 편집 시각 디자인을 자율적으로 완성하며, 주체, 재질, 색상, 폰트, 아카이브, 구도 및 정보 계층을 자동으로 결정합니다.

9:16 세로 형식, 극도로 간결하고 절제된 스타일에 대면적 여백을 둡니다. 주제를 핵심으로 삼아 주체를 주요 시각 구조로 만들며; 전경, 중경, 원경의 공간 관계를 구축하고, 잘림, 겹침, 부유, 투광, 가상 초점, 사선으로 화면에 들어오거나 벗어나는 방식으로 자연스러운 공간 깊이를 형성합니다.

주체, 여백, 재질과 텍스트가 비대칭 편집 그리드를 구성합니다; 보조 아카이브는 두 번째 시각 층으로 작용하며, 주체와 명확한 크기, 선명도, 공간 차이를 형성합니다.

주제에 적합한 재질, 색상 및 아카이브 형식을 자동 선택하며, 실제 재질, 자연광 그림자와 종이 또는 전시 공간의 공기감을 유지합니다. 텍스트는 간결하게 구성되어 대제목, 중형 설명, 소형 아카이브 정보 계층을 형성합니다. 텍스트는 위 에 있는 내용만 사용하고, 확인되지 않은 내용은 텍스트로 넣지 않습니다.

전체적으로 현대 미술관 전시 주 시각이나 고급 예술 출판물처럼 제시: 조용하고, 절제되며, 공간감, 재질감과 지식성을 가집니다.

복잡한 중첩, 장식화, 전통 중국풍 템플릿, 상업 광고 느낌, 주체의 완전한 중앙 배치, 과도한 앤티크 처리, CG 플라스틱 느낌, 무의미한 텍스트를 피합니다.
