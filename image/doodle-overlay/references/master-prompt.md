# Master Prompt — Doodle Overlay

Fill the [BRACKETS], then paste the whole block as the image prompt,
with the user's photo attached.

Subject mode: [SUBJECT — "cat" or "figure (cute kid / animal / cartoon character)"]

```
Transform the attached photo into a mixed-media editorial illustration:
PHOTOGRAPHY x WHITE HAND-DRAWN DOODLE CHARACTER.

## 1. Preserve the photo
Keep the uploaded photo's real content as complete as possible: real
scene, subject buildings / landmarks / people / roads / water /
mountains / trees / sky, original composition, camera angle, perspective,
light direction, atmosphere, photographic texture. Do not change the
location, redesign the subject architecture, or alter the core real
spatial relationships. The photo's key subjects must stay clear, real,
and recognizable.

## 2. The character
Draw ONE oversized white hand-drawn line-art [SUBJECT] ON TOP of the
photo. The character must interact with the real environment in a way
that is clever, funny, natural, and instantly readable — as if it were
really there.

Interaction: [INTERACTION — one concrete action tied to THIS photo.
Cat mode: the cat plays mischief with a real structure (e.g. "the cat
hugs the tower with both front paws as if it were a scratching post,
tail curling around the antenna"). Figure mode: the figure REINTERPRETS
a real object into something else (e.g. "a giant kid blows the tower
like a straw stuck in a juice box", "a kid wears the roof as a hat").
Never just stand the character next to the building — the character
must physically engage the real object.]

Scale: surreal scale play — the character is clearly larger than life
next to the scene. Cat: about 70% of a full giant-monster scale
(slightly restrained, never overwhelming the frame). Figure: typically
larger than the buildings, full giant scale play allowed. Pose and
perspective must feel physically plausible inside the photo's space.

Character style: simple, natural, slightly childlike white line art —
white marker / white chalk / fine white pen drawn directly on the photo.
Line weight varies slightly. Outlines clear but never over-complex. NO
realistic detail, NO refined manga style, NO heavy or black outlines,
NO 3D cartoon feel, NO sticker look.

Character face and action: minimal features — gentle, curious, natural,
humorous. Cat: dopey, mischievous, healing; playing, napping, peeking,
pouncing, leaning, stretching a paw, nuzzling, chasing, hiding.
Figure: smiling, focused, surprised, working hard, secretly playing,
hugging, knitting, fixing, carrying, blowing, wrapping, watering.

## 3. Accents
The doodle layer is white line art FIRST. You may add a small amount of
ONE low-saturation yellow (mustard / warm / golden) for tiny focal
points only: small stars, small hearts, small flowers, small sparkles, a
tiny butterfly or fish, a scarf, yarn, a balloon, food, a ribbon, music
notes, the small prop the character is playing with, or a warm highlight
cue. Keep yellow restrained — never let it dominate.

Sparingly, you may also add: motion lines, a tiny heart, a tiny star, a
wagging-tail line, paw action lines.

[Cat mode only] Optional caption: ONE short handwritten phrase in the
SAME white as the cat (e.g. "caught you!", "mine now", "shhh..."). Tiny
and casual; it must never dominate. [CAPTION, or omit entirely]
[Figure mode: no text, no titles, no logos, no watermarks.]

## 4. Composition
The photograph remains the visual foundation. Place the character using
the photo's own structure — open sky, lawn, wall, water, road, building
edges, horizon, windows, trees, bridges. Never cover the most important
architectural details. The character and the real objects must share
accurate spatial, perspective, and action relationships: readable at
first glance, delightful at second glance. Keep ONE core visual idea
per image — never stack elements for the sake of creativity.

## 5. Mood
Minimal, clean, humorous, designed, narrative, with visual contrast and
a healing feel — high-end creative-ad / editorial-illustration quality.
The final effect: reality reimagined by an imaginative doodle.
Photography carries the real; lines carry the imagination.

## Negative
Do not alter the core structure of the real architecture. Do not redo
the background. Do not add extra characters. Do not draw many
characters. Do not fill the frame with doodles. No generic sticker
effect. No 3D cartoon. No black heavy outlines. No complex manga style.
No realistic colored character. No large solid color fills. Keep the
photo's subject clearly recognizable, keep the photographic texture,
and keep the doodle naturally fused with the photo. Clever, not merely
cute.
```

## Interaction tables

Pick the family that fits the photo, then invent a photo-specific
variation. Never repeat the same interaction across photos.

### Cat mode — mischief with real structures

| Photo element | Cat interaction |
|---|---|
| Tower / antenna / streetlight | stretches a paw at it, hugs it, treats it as a cat toy |
| Bridge / railing / wire / road | toy beside its tail, pawing the line, walking it like a catwalk |
| Roof / wall / hillside / lawn | napping, rolling, peeking over, sunbathing |
| River / lake / water / reflection | looking down at its own reflection, pawing the water, chasing the reflection |
| Window / doorway / opening / gap | secretly peeking out, playing hide-and-seek, watching from behind |
| Branch / flower / cloud / sky | pouncing at a butterfly, sniffing a flower, chasing something drifting |
| Food / roadside object / car / light | curious approach, testing with a paw, trying to steal a play |

### Figure mode — reinterpreting real objects

The figure turns a real object into something else entirely. Do not
apply the examples mechanically — judge the best fit for the actual
photo.

| Photo element | Reinterpreted as |
|---|---|
| Building | food / instrument / toy / gift / clothing / daily object |
| Tall tower | microphone / straw / pencil / candle / knitting needle |
| Round building | plate / button / wheel / balloon / bead |
| Bridge | guitar strings / clothesline / jump rope |
| Wall / road | yarn / scarf / zipper / ribbon |
| Mountain peak | pillow / cake / hat |
| Lake / river | water in a cup / mirror / bathtub |
| Roof | hat / gift wrap / blanket |
