# Overlay Modules — Doodle Overlay

Optional layers that stack on the doodle-overlay base (photo preservation +
white hand-drawn language always apply). Pick **at most 2 modules per
image** — character + one text module is the sweet spot. One core visual
idea per image.

M1 (character: cat / figure) lives in `master-prompt.md` and is the default
hero layer. The modules below are M2–M7. Each block is paste-ready English;
fill [BRACKETS].

---

## M2 — Handwritten text only

Use when the user wants just phrases in the same style, no character.

```
On the photo, add [1–3] short handwritten phrases in the same white
hand-drawn style as the doodle layer: white paint marker, slightly
transparent, small, naturally integrated into the photographic space —
never oversized, never covering key subjects.
Phrases: "[PHRASE 1]" / "[PHRASE 2]"
Placement: [e.g. upper-left negative space / along the horizon]
Style: casual handwriting, uneven baseline, as if written directly on
the photo. Restrained hearts / stars / exclamation marks allowed.
```

## M3 — Doodle icon set

Use when the user wants cute icon-like drawings added.

```
Add a small set of [3–9] cute hand-drawn doodle icons in the same white
line-art style, each depicting one distinct thing visible in the photo:
[ICON LIST — e.g. church spire, ferry, swan].
Arrange them [loosely scattered across negative space / on a loose grid
in one corner].
Each icon: simple, minimal, instantly readable, same white marker line
weight as the doodle layer. No color fills; tiny mustard-yellow accents
allowed on at most one icon.
```

## M4 — Postcard

Use for travel-postcard treatment of the photo.

```
Treat the photo as a travel postcard. Keep the photo full-bleed and
faithful. Add in the white hand-drawn style:
- a hand-lettered place name: "[PLACE]" — playful, slightly large, in a
  clear area of sky / wall / water
- 2–4 tiny travel doodles: a stamp-like icon, a mini route line with an
  arrow, a small weather symbol, a tiny food or landmark icon
- one short message line: "[MESSAGE]" in casual handwriting
Everything in white line art; restrained mustard-yellow on at most two
tiny accents.
```

## M5 — Editorial / magazine cover lines

Use for fashion-magazine typography over the photo.

```
Treat the photo as a fashion-magazine cover. Keep the photo full-bleed
and faithful; leave clean negative space for type. Add editorial
typography:
- masthead-style title: "[TITLE]" — elegant serif, moderately large,
  top area
- 2–4 cover lines: "[LINE 1]" / "[LINE 2]" — mixed serif/sans, small,
  placed along edges in quiet areas
- optional issue line: small "[ISSUE / DATE]"
Typography must be clean and legible — no gibberish lettering. No
barcode unless requested.
```

## M6 — Promo copy (fashion / beauty / bag / furniture)

Use for product-promotion text over a lifestyle photo.

```
Treat the photo as a product advertisement for [PRODUCT CATEGORY].
Keep the photo faithful; the product (if visible) stays the hero. Add
promo typography in a style matching the product mood (luxury = elegant
serif; street/casual = bold sans):
- headline: "[HEADLINE]" — short and specific, under 8 words
- 1–2 benefit lines: "[BENEFIT]" — one concrete benefit per line, no
  generic claims like "best quality"
- optional CTA line: "[CTA]"
All type clean and legible, positioned in negative space, never covering
the product or key subjects.
```

## M7 — Hand-drawn doodle scatter

Use when the user wants cute hand-drawn doodles scattered over the
photo ("손그림 낙서" / "낙서 추가") — stars, hearts, music notes,
flowers, tiny cat faces, squiggles — plus optional short handwritten
phrases. No giant character, no info annotations; this is the light,
playful layer that makes a photo feel like a decorated journal page.

```
Scatter [5–12] small white hand-drawn doodles across the photo in
the same white line-art style: stars (4-point sparkles and 5-point
outlines), small hearts, music notes, simple flowers, tiny cat
faces, small spirals or squiggle arrows.
Placement: loosely scattered through negative space — corners,
sky, walls, floor — never covering faces or the main subject.
Style: casual pen strokes, slightly transparent white, varied
sizes, childlike and cute. [PHRASE OPTION: also add 1–3 short
handwritten phrases in the same white style — e.g. "[PHRASE 1]" /
"[PHRASE 2]" — placed in open space, casual handwriting, uneven
baseline.]
Film-strip option: if requested, present the photo as [N] film
frames with black borders and "PHOTO 2000" side text, doodles
scattered across the frames.
```

## Combination rules

- Max 2 modules per image. Recommended pairs: M1+M2 (character + phrase),
  M4 alone (postcard), M5 alone (editorial), M1+M3 (character + icons),
  M7 alone (doodle scatter), photo + M6 (promo).
- M5/M6 use clean editorial typography (serif/sans), not the hand-drawn
  marker style — they are type overlays, not doodles.
- Everything else (photo fidelity, no clutter, clever-not-cute) follows
  the base rules in SKILL.md.
