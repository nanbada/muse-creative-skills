# New Japan-Side Account Setup Checklist

Run this for every new Japan-targeted Instagram/SNS account so the playbook applies from post one.

## Profile
- [ ] Handle + display name decided (user confirms)
- [ ] Bio: name｜age｜city / one-line identity / contact (JP-first wording)
- [ ] Profile AI label ON (for AI-persona accounts)
- [ ] Profile photo set (manual if automation is blocked)

## Defaults (from this playbook, pre-applied)
- [ ] Caption style: `references/caption-style.md` (early-20s colloquial, checklist-verified)
- [ ] Hashtag starter set: brand tag + 3–4 rotating topic tags (≤5 total, JP+EN mix)
- [ ] Posting window: account insights follower hours (fallback: carousel weekday 8–10/12–14 JST, overall prime 19–21 JST)
- [ ] AI-generated content label ON for every post
- [ ] Carousel format: `references/carousel-playbook.md` (8–10 slides, 4:5, save CTA)

## Launch
- [ ] First 3 posts planned (hook-first captions drafted + checklist passed)
- [ ] User approves bio, first captions, and posting cadence before anything goes live
- [ ] Account recorded in memory with its hashtag set and cadence

## Operating Rules
- Publishing always needs explicit user approval per post (no auto-publish).
- 2FA/CAPTCHA blocks: stop, never bypass — especially on new accounts (lock risk).
