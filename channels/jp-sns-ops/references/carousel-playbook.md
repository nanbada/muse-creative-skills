# Carousel Playbook — Instagram Card-News (Japan)

Researched 2026-10-11, global + Japan (index-based; keep the full report alongside the skill).

## 10 automation patterns (each seen in 3+ independent viral posts)
1. **Cover formula**: {N} {items} + {concrete payoff} + "(most miss #{k})" / JP: 「保存版」+ conclusion big on slide 1. EN ≤12 words / JP ≤25 chars.
2. **Slide count**: 8–10 (hook 1 + body 6–8 + recap 1 + CTA 1). Platform max is 20; sweet spot is 6–10.
3. **One slide = one point**, one visual anchor (icon/photo/chart) per slide. ≤30–50 words / ≤25 chars per slide.
4. **Last slide = recap + save CTA**: "Save this for later" / 「保存してね」.
5. **Color**: max 3-color palette, unified across all slides.
6. **Branding set**: slide numbers (n/10), swipe indicator on slide 1, brand color/logo every slide, face + CTA on last slide.
7. **Ratio**: 4:5 (1080×1350), identical on every slide (slide 1 sets the ratio).
8. **Typography**: bold gothic headline + 1 body font (max 2). High contrast (white/black + outline), min 48pt. JP pair: はんなり明朝 + Noto Sans JP.
9. **Swipe triggers**: mid-sentence cut ("…→"), curiosity gap ("slide 5…"), value bomb on slide 3.
10. **Caption**: line 1 = slide-1 hook, body expands (never repeats slides), ends with question/micro-CTA, ≤5 hashtags.

## Hook formulas (quote bank)
- Number + open loop: "7 portfolio mistakes… (most do #4)"
- Confession: "I've been doing this wrong for two years"
- Deadpan rejection: "Society accepted ✔ / Society rejected ✗", "wtf is a decaf??"
- JP: 「保存版」+ big conclusion on slide 1; 「副業初心者がやるべき3つのこと」

## JP 10-slide standard
1: hook → 2–8: one info each → 9: recap → 10: save CTA. ≤25 chars/slide, ≥48pt, timing per skill workflow step 4.
