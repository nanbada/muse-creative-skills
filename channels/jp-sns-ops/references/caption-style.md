# Caption Style — Early-20s Japanese Instagram Colloquial (かわいい 구어체)

Researched 2026-10-12 from popular Japanese Instagram creators (index-based; keep the full report alongside the skill).

## Core formula
**です・ます + ため口 mix.** Never all-formal, never all-casual. The winning combo is politeness + unfiltered feeling (本音).

## 20s markers (use naturally, don't force)
- Endings: 〜なの / 〜だよ / 〜かも / 〜かな / な。。 / よーーー
- Emphasis: だいすき, めっちゃ, 〜すぎるーー, わーー, 本当に本当に
- Lingering: 。。(double period), …, 〜, ーー
- Onomatopoeia: どきどき, わくわく
- Address fans as みんな (not 皆様)
- 1st person: 私 / わたし (あたし・うち unverified in sample — treat as character-specific, don't generalize)
- Trending flavor (use sparingly, mostly in fan-facing replies): メロい, ホビ (ホビ服/ホビ飯)

## Emoji
- Family: 🤍 🎀 ✨ 💕 🥺 (+ 💌 👍 💬 for CTAs)
- Placement: end of sentence only, 1–3 per sentence, 1–5 per post
- Young creators also use kaomoji; don't overdo it

## Rhythm
- 1 sentence = 1 line, blank lines between beats
- Hook in the first 1–2 lines (declaration / ＼＼decoration／／ / exclamation + hook word like 保存必須)
- Occasional 体言止め (ending a sentence on a noun) reads human; don't overuse

## CTA — request/question tone, never command
- 〜してね / 〜してください / 〜と嬉しい・励みになります / question form
- Real patterns: 「シェアしてね💌」「コメント💬で教えてね」「似合ってますか？」「参考になったら👍のスタンプで教えてね」

## Hashtags
- Max 5 per post (Instagram 2026 official limit), end block (not inline)
- JP-centric + 1–2 English: e.g. #上高地 #kamikochi
- Mix sizes 大/中/小; brand/attribute tags for fashion (#UNIQLO #骨格ウェーブ); one original brand tag per account (e.g. #あおい daily tag)
- No unrelated big tags; don't repeat the identical set every post

## Don't (reads stiff / AI-like to Japanese readers)
- All-です・ます with zero feeling; 「〜することが重要です」repetition
- 「この〜について解説します」openers; 「いかがでしたでしょうか」「ぜひ参考にしてください」closers
- 「させていただきます」「〜となっております」over-keigo
- Translationese: 「〜することが可能です」「〜という点において」
- Abstract info-dump with no personal feeling, no proper nouns, no numbers

## Pre-publish checklist (10)
1. Hook in first 2 lines? 2. ですます + ため口 mixed? 3. One sentence per line? 4. Concrete names/numbers/places? 5. One line of real feeling? 6. No ending repeated 3×? 7. Emoji only at sentence ends? 8. CTA is request/question tone? 9. ≤5 relevant hashtags? 10. Reads like talking to a friend out loud?

## Rewrite example (fashion)
Before: 「今日のコーディネートです。ニットとスカートを合わせました。とても気に入っています。」
After:
> 今日の通学コーデ🤍
> ニットのゆるっと感だいすきなの🥺
> スカート合わせたら足長くみえちゃう！！
> みんなはゆるニット派？ぴたっと派？💬
>
